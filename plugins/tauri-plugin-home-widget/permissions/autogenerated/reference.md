## Default Permission

Aucune permission : le widget d'écran d'accueil n'expose aucune commande à
l'interface. Sa mise à jour (`update`) et la lecture des actions faites sur le
widget (`peek_actions`, `ack_actions`, `on_action`) restent réservées au code
Rust de l'appli.
